## 1. Цель и решение игрока

Сейчас контакт = война со всеми соседями сразу, войну нельзя закончить, землю не за что брать, кроме самой земли. Этот кусок даёт войне начало, цель и конец.

| Решение | Варианты | Цена |
| --- | --- | --- |
| **С кем воевать** | объявить войну одному из соседей / ждать | его дивизии теперь идут на тебя; пока у тебя одна война, вся армия на одном фронте |
| **Ради чего** | **территориальные претензии** на район у границы / **репарации** | претензии: земля навсегда, но надо взять и удержать район; репарации: деньги сейчас, занятое возвращается |
| **Когда остановиться** | заключить мир сразу, как цель выполнена / давить дальше к столице | давить дальше — та же цель, но больше потерь и риск, что защитник отобьёт 10% твоей земли и мир навяжет он |
| **Мириться, когда не выходит** | предложить белый мир (каждый оставляет занятое) / держаться | белый мир фиксирует линию фронта; через 8 минут война кончается так сама |

Ключевая развилка — **земля навсегда или деньги сейчас.** Второе следствие: мир закрывает фронт, дивизии уходят в тыл, и вся армия свободна для следующей войны. Кусок закрывает оба отступления этапа 1: «контакт = война» и «карман без отдельного фронта» (последнее решаем дешевле, чем в плане, раздел 4.6).

**Честно о таймере.** Сам по себе этот кусок 97% партий по таймеру не вылечит: конец партии по правилу приходит с календарём и тремя победами в куске 3. Отсюда ждём три вещи, и их меряем: войны начинаются и кончаются, у партии появляется ритм «война — перемирие — война», занятая земля закрепляется миром (лидер растёт быстрее, чем сейчас). Цели ворот 2 этот кусок не обязан выполнять.

**Отступления от брифа 05.** (1) Городов ещё нет (кусок 4), поэтому претензии ставятся не на город, а на **район**: круг радиуса 18 px вокруг выбранной точки у границы. Когда появятся города, центр района будет привязываться к городу; формат команды тот же. (2) Время в минутах игрового таймера, не в годах: календарь — кусок 3. 5 лет перемирия = 5 минут, 8 лет войны = 8 минут.

## 3. Данные

### 3.1. Слои пикселей

`Core : NativeArray<byte>` на пиксель — **исконный владелец**: чья это земля по миру. `Owner` — кто держит сейчас. Пиксель **занят**, если `Owner ≠ 0`, `Core ≠ 0`, `Owner ≠ Core`.

- После генерации: `Core = Owner`.
- Расползание по ничьей земле (`d = 0` в `ApplyFrontJob`): `Core = a`.
- Захват на войне: `Core` не меняется.
- Мир, гибель нации, карманы: раздел 4.

`OccupiedLen : NativeArray<int>` `(N + 1)²`, `[holder × (N + 1) + core]` — сколько пикселей нации `core` держит `holder`. Ведётся инкрементально в `ApplyFrontJob`: при переходе пикселя `t` от `d` к `a` с `c = Core[t]`: если `c ≠ 0` и `c ≠ d` → `OccupiedLen[d, c]−−`; если `c ≠ 0` и `c ≠ a` → `OccupiedLen[a, c]++`. Производное: не в хеше, пересчитывается в `DerivedStateMatches`.

### 3.2. Состояние пары (`Wars : NativeArray<War>` `N × N`, используется только `a < b`, доступ `WarOf(a, b)` в любом порядке)

| Поле | Тип | Что это |
| --- | --- | --- |
| `Status` | `byte` | 0 мир, 1 война, 2 перемирие |
| `Attacker` | `byte` | кто объявил; 0 — нет войны |
| `Goal` | `byte` | 1 претензии, 2 репарации |
| `ClaimCenter` | `int` | пиксель центра района; −1 у репараций |
| `ClaimTotal` | `int` | пикселей района с `Core = защитник` на момент объявления |
| `StartTick` | `int` | тик объявления |
| `PreWarAtt`, `PreWarDef` | `int` | `Pixels` сторон на момент объявления |
| `HoldAtt`, `HoldDef` | `short` | сколько секунд подряд выполнено условие цели нападающего / победы обороны |
| `OfferFrom` | `byte` | кто предложил белый мир; 0 — нет предложения |
| `OfferUntil`, `OfferCooldownUntil` | `int` | срок предложения; раньше этого тика сторона не может предложить снова |
| `PendingPeace` | `byte` | 0 нет; 1 белый, 2 претензии, 3 репарации, 4 победа обороны — разрешится в начале тика `WarSystem` |
| `TruceUntil` | `int` | конец перемирия |
| `TributePayer`, `TributePayee` | `byte` | репарации: кто платит кому; 0 — нет |
| `TributeUntil` | `int` | до этого тика платит |

Чтение наружу: `AtWar(a, b)`, `InTruce(a, b)`, `GoalFulfilled(a, b, side)`, `ClaimHeld(a, b)` (пикселей района, которые держит нападающий, считает `WarSystem` раз в секунду и хранит в производном массиве `ClaimHeldLen`, не в хеше).

### 3.3. Команды

```csharp
DeclareWar   = 11,  // A = id противника, B = 0 — репарации; B = 1 + пиксель — претензии на район с центром в пикселе B − 1
ProposePeace = 12,  // A = id противника
AnswerPeace  = 13,  // A = id того, кто предложил; B = 1 принять / 0 отказать
// RejectReason дописать:
NotAtWar = 25, AlreadyAtWar = 26, TruceActive = 27, ClaimInvalid = 28, NoOffer = 29, PeaceCooldown = 30
```

- **DeclareWar.** Нация жива; `A` жив и `≠ Nation` (`TargetInvalid`); `FrontLen[Nation, A] > 0` (`NoContact`); статус пары: война → `AlreadyAtWar`, перемирие → `TruceActive`. Претензии (`B ≥ 1`), иначе `ClaimInvalid`: пиксель `p = B − 1` в карте, `Owner[p] = Core[p] = A`; расстояние Чебышёва от `p` до ближайшего пограничного пикселя пары (`Nation`, `A`) ≤ `claimMaxDepth` (проход по `Frontier`); ни один пиксель круга `claimRadius` вокруг `p` не лежит в `CapitalCover` противника; `ClaimTotal ≥ claimMinPixels`. Применение: `Status = 1`, `Attacker = Nation`, `Goal`, `ClaimCenter`, `ClaimTotal`, `StartTick = Tick`, `PreWar*` = текущие `Pixels`, всё остальное в 0 (`OfferFrom`, `Hold*`, `PendingPeace`, дань). Приказы обеих сторон на этой паре остаются, какими были (по умолчанию оборона).
- **ProposePeace.** Пара в войне (`NotAtWar`). Если у отправителя выполнена своя цель (`HoldAtt ≥ goalHoldSeconds` у нападающего, `HoldDef ≥ goalHoldSeconds` у защитника) → `PendingPeace` = 2 / 3 (по цели нападающего) или 4 (защитник): мир на своих условиях, согласия не нужно. Иначе: если есть предложение от противника (`OfferFrom = A`, срок не вышел) → `PendingPeace = 1` (это принятие). Иначе `Tick < OfferCooldownUntil` для отправителя → `PeaceCooldown`; иначе `OfferFrom = Nation`, `OfferUntil = Tick + offerTicks`, `OfferCooldownUntil = Tick + offerCooldownTicks`.
- **AnswerPeace.** Пара в войне, `OfferFrom = A`, `Tick < OfferUntil` (`NoOffer`). `B = 1` → `PendingPeace = 1`; `B = 0` → `OfferFrom = 0`. `B ∉ {0,1}` → `OrderInvalid`.

Если в одном тике пришло несколько команд на одну пару, применяются по порядку очереди; первая, поставившая `PendingPeace ≠ 0`, выигрывает, следующие команды мира на эту пару в этом тике отклоняются `NotAtWar`.

### 3.4. Хеш

После `Biome` — `Core` целиком; после `FrontOrder` — `Wars` по индексам `a < b`, все поля в порядке таблицы 3.2. `HashJob` и `HashManaged` вместе. `DerivedStateMatches`: `OccupiedLen`, `ClaimHeldLen`, `Pixels`.

### 3.5. Ручки (`rules.war`)

| Ручка | Старт | Зачем |
| --- | --- | --- |
| `claimRadius` | 18 | район ~1 000 px, примерно восьмая часть средней нации |
| `claimMaxDepth` | 30 | центр района у границы, не в глубине |
| `claimMinPixels` | 300 | район не из одной воды |
| `claimHold_bp` | 7 000 | держишь 70% района |
| `repOccupy_bp` | 1 000 | репарации: занял 10% его довоенной земли |
| `defenseWin_bp` | 1 000 | победа обороны: защитник занял 10% земли нападающего |
| `goalHoldSeconds` | 20 | условие цели держится 20 с подряд |
| `tribute_bp` | 5 000 | платит половину дохода |
| `tributeTicks` | 3 000 | 5 минут |
| `truceTicks` | 3 000 | 5 минут |
| `maxWarTicks` | 4 800 | 8 минут — и белый мир сам |
| `offerTicks` | 100 | предложение живёт 10 с |
| `offerCooldownTicks` | 600 | не чаще раза в минуту |

`tribute_bp` 5 000, а не 30% из брифа: при 30% репарации за 5 минут дают ~450 золота, это меньше одной пехотной дивизии, и «деньги сейчас» проигрывают «земле навсегда» без вопросов (пример в разделе 5). Половина дохода даёт ~750, то есть полторы дивизии в момент, когда они нужнее всего.

## 4. Правила и формулы

### 4.1. Война открывает фронт

- `FrontSystem.FillTables`: для `d ≠ 0` шанс пары `(a, d)` = 0, если `!AtWar(a, d)`. Расползание по ничьей земле (`d = 0`) без изменений.
- `FrontLen` и `FrontTerrainLen` считаются по всем контактам, как сейчас: это и **граница** (мир, перемирие), и **фронт** (война). `AssignDivision` по-прежнему требует только `FrontLen > 0`: дивизии можно поставить к мирной границе заранее. Там они не дают силы (шанс 0) и восстанавливают организацию как на фронте (`orgRecoverFront_bp`), пополняются как на фронте.
- `World.Attacking(v)` дополнительно требует `AtWar(v.Owner, v.Front)`. Отсюда: на мирной границе нет ни наступления, ни потерь, ни трат организации.
- `NetFlips10s`, `FlipHistory` — как есть.

### 4.2. Цели (`WarSystem`, раз в секунду, на том же тике, что экономика, до неё)

Для каждой пары `a < b` в войне, нападающий `A`, защитник `D`:

```
ClaimHeldLen = #{ p в круге claimRadius вокруг ClaimCenter : Core[p] = D и Owner[p] = A }          // только претензии
attOk = Goal = претензии ? ClaimHeldLen × 10000 ≥ claimHold_bp × ClaimTotal
                         : OccupiedLen[A, D] × 10000 ≥ repOccupy_bp × PreWarDef
defOk = OccupiedLen[D, A] × 10000 ≥ defenseWin_bp × PreWarAtt
HoldAtt = attOk ? min(HoldAtt + 1, 32 000) : 0;   HoldDef = defOk ? min(HoldDef + 1, 32 000) : 0
если Tick − StartTick ≥ maxWarTicks и PendingPeace = 0:  PendingPeace = 1                          // застрявшая война
если OfferFrom ≠ 0 и Tick ≥ OfferUntil: OfferFrom = 0
```

Цель выполнена, пока `Hold ≥ goalHoldSeconds`. Если условие сорвалось, счётчик сбрасывается: отбили район — кнопка мира гаснет. Если обе стороны выполнили свои условия одновременно, право на мир у обеих, выигрывает тот, чья команда раньше в очереди.

Для перемирия: `Tick ≥ TruceUntil` → `Status = 0`, поля войны обнуляются (кроме дани, у неё свой срок).

### 4.3. Разрешение мира (`WarSystem`, в начале каждого тика, первой системой; пары по возрастанию `a < b`)

Для пары с `PendingPeace ≠ 0` один Burst-проход `PeaceJob` по карте:

| Вид | Пиксели `Owner = A, Core = D` | Пиксели `Owner = D, Core = A` | Район | Дань |
| --- | --- | --- | --- | --- |
| 1 белый | `Core = A` (закреплены) | `Core = D` (закреплены) | — | — |
| 2 претензии | `Core = A` | `Owner = A` (вернулись) | все пиксели круга с `Owner = Core = D` → `Owner = Core = A` | — |
| 3 репарации | `Owner = D` (вернулись) | `Owner = A` (вернулись) | — | `D` платит `A` |
| 4 победа обороны | `Owner = D` | `Owner = A` | — | `A` платит `D` |

Потом по порядку:
1. Карманы (4.6).
2. `Pixels` обеих наций пересчитываются этим же проходом; `OccupiedLen` по паре — тоже.
3. `Status = 2`, `TruceUntil = Tick + truceTicks`; `Attacker`, `Goal`, `ClaimCenter`, `ClaimTotal`, `Hold*`, `OfferFrom`, `PendingPeace` → 0 / −1. Дань: `TributePayer`, `TributePayee`, `TributeUntil = Tick + tributeTicks`.
4. Дивизии обеих сторон с `Front` = другая сторона → `Front = 0`, `ArriveTick = 0` (в тыл сразу). `FrontOrder` пары с обеих сторон → оборона.
5. `RebuildFrontier`, `RecountFrontLen`, `MarkAllDirty`.

Столица в мире не двигается: пиксель столицы нельзя занять (его захват убивает нацию), а район претензий не пересекается с `CapitalCover`.

### 4.4. Репарации (`EconomySystem`)

После дохода и содержания, до дезертирства, по парам `a < b` по возрастанию: если `TributePayer ≠ 0` и `Tick < TributeUntil`, `pay = Income(payer) × tribute_bp / 10000` (валовой доход из `EconomySystem.Income`, деление к нулю), `pay = min(pay, Gold(payer))`, у плательщика `Gold −= pay`, у получателя `Gold += pay`. Плательщик мёртв — дань снимается. Репарации не уводят золото в минус и не вызывают дезертирство сами по себе.

### 4.5. Гибель нации

Капитуляции отдельной нет: взял столицу — нация пала, как сейчас. В `KillNation` дописать: пиксели `Owner = d` → `Owner = 0`, `Core = 0`; пиксели `Core = d` у других наций → `Core = Owner` (занятое закрепляется за тем, кто держит); все пары с `d` → статус мир, поля обнулены, дань с `d` и в пользу `d` снимается. `OccupiedLen` пересчитать целиком.

### 4.6. Карманы при мире

После прохода мира — заливка (`PocketJob`, Burst, `IJob`, очередь и метки во временных массивах) по связным по 4-соседству компонентам суши с `Owner = D` без столицы `D`. Если **все** соседи-суша компоненты принадлежат `A`, компонента целиком → `Owner = Core = A`. То же с ролями наоборот. Карманы у третьих наций и у ничьей земли не трогаем.

Во время войны карман по-прежнему держит только гарнизон, а `surroundMult_bp` быстро его съедает. Карман как отдельный фронт во время войны — бэклог.

### 4.8. Старт

Все пары — мир. `Core = Owner` после генерации. Первый контакт ничего не открывает: соседи расползаются до общей границы и стоят.

### 4.9. ИИ (`AiSystem`, одна команда за раз, как в 01c)

`IsFront(w, self, d)` из 01c (цель, угроза, приказы, закрытие прорыва, ротация, `spread`) теперь значит **фронт войны**: `FrontLen > 0` и `AtWar`. Добавляются правила (порядок сверху вниз, до правил 01c, кроме «в тыл обескровленную»):

0. **Ответ на предложение.** Есть живое предложение белого мира от `d` → `AnswerPeace d, 1`, если `OccupiedLen[self, d] ≥ OccupiedLen[d, self]` (линия фронта не в убыток) или `threat(d) ≥ threatRatio_bp`; иначе `AnswerPeace d, 0`.
1. **Забрать выполненное.** Своя цель выполнена → `ProposePeace d` (профиль `base` забирает сразу; «давить дальше к столице» — для типа «Генерал» в куске 7).
2. **Предложить белый мир, когда не выходит.** Война идёт ≥ `peaceAfterTicks`, у противника `HoldDef` или `HoldAtt` растёт против нас (его условие выполнено хотя бы наполовину), `threat(d) ≥ threatRatio_bp` → `ProposePeace d`.
3. **Правила 01c** 1–5 (в тыл обескровленную, прорыв, ротация, кулак, приказы) — по фронтам войны.
4. **Подготовка и объявление**, если у ИИ нет войн, которые он начал (`maxOwnWars` = 1):
   - кандидат `c` — сосед в мире (не перемирие) с максимальным `ratio(c) = Σ своих готовых atk100 по равнине × Strength / max(1, Σ их живых def100 по равнине × Strength)`; при равенстве меньший id; без шума, чтобы кандидат не прыгал;
   - объявлять, если `ratio(c) ≥ declareRatio_bp` или с начала партии / конца последней своей войны прошло `idleWarTicks` (против пацифизма, тогда кандидат — тот же argmax);
   - **подготовка**: пока доля своих готовых дивизий на границе с `c` < `stageShare_bp` и есть свежая в тылу → `AssignDivision k, c`. На карте игрок видит, как сосед стягивает дивизии к границе;
   - иначе → `DeclareWar c, цель`: претензии с вероятностью `claimsChance_bp` (поток `Ai`), иначе репарации. Центр района: пограничные пиксели пары на стороне `c` по возрастанию индекса, медианный, сдвиг на `claimRadius` к столице `c` целыми шагами Брезенхэма, пока пиксель принадлежит `c`; не прошёл валидацию → репарации.
5. **Набор** — правило 6 из 01c.

`spread`: правила 0–2 и 4 как у `base`, правила 01c — как в 01c. `no_armor` — как в 01c.

## 5. Пример расчёта

Ольстран (2) объявляет войну Альварии (1). Довоенная земля: Ольстран 6 400 px, Альвария 6 000 px.

**Претензии.** Район радиусом 18 даёт `ClaimTotal = 1 012` пикселей Альварии. Нужно держать 709 пикселей: сравнение `held × 10 000 ≥ 7 000 × 1 012` даёт `held ≥ 708,4`. На 140-й секунде Ольстран держит 731 пиксель района: `attOk`, `HoldAtt = 1`. Двадцать секунд подряд → цель выполнена, Ольстран шлёт `ProposePeace 1`, на следующем тике `PendingPeace = 2`: всё занятое закрепляется, оставшиеся 281 пиксель района с `Owner = Core = 1` переходят Ольстрану. Если Альвария на 150-й секунде отбила 30 пикселей (701 < 709), `HoldAtt = 0` и счёт начинается заново.

**Репарации, та же война.** Нужно занять `6 000 × 1 000 / 10 000 = 600` px Альварии. При мире они возвращаются. Доход Альварии `200 + 6 000 × 100 / 2 000 = 500` в сотых/с. Дань `500 × 5 000 / 10 000 = 250` → 2,5 золота в секунду, за 300 с — 750 золота: полторы пехотные дивизии. При 30% было бы 450, ровно одна.

**Сравнение с претензиями:** район ~1 000 px — это `+1 000 × 100 / 2 000 = 50` в сотых/с навсегда, за оставшиеся ~25 минут партии ~750 золота, плюс земля к 40% победы, но медленно. Репарации — те же деньги сразу и без земли. Это и есть развилка.

**Победа обороны.** Альвария отбилась и заняла `6 400 × 1 000 / 10 000 = 640` px Ольстрана, держит 20 с → `ProposePeace 2` от Альварии, `PendingPeace = 4`: всё занятое обеими сторонами возвращается, Ольстран платит Альварии половину своего дохода 5 минут.

Тесты повторяют все четыре случая на синтетической карте и числа 709 / 600 / 250 / 640.

## 6. Тик и цена по CPU

- Обычный тик: +проверка `AtWar` на пару в `FillTables` (≤ 81 пара), +одно чтение и одна запись `Core` на переход пикселя в `ApplyFrontJob`. Ожидание: средний тик не вырастет больше чем на 0,005 мс (сейчас 0,061).
- Раз в секунду: `ClaimHeldLen` — круг ~1 000 px на войну с претензиями, войн ≤ 28. Пренебрежимо.
- Тик мира: проход по 131 072 пикселям + заливка карманов + `RebuildFrontier`. Burst, цель ≤ 2 мс (это p99-бюджет). Мир — редкое событие, но в отчёте показать максимум тика отдельно; не уложились — записать цифру, не подгонять.
- Память: +128 КБ (`Core`), `Wars` 64 × ~48 байт.

## 7. Отчёт и `-analyze`

`MatchResult` и строки `report.md`:
- войн за партию (среднее, медиана), длина войны (медиана, мин);
- исходы войн: претензии, репарации, победа обороны, белый мир по предложению, белый мир по сроку, война кончилась гибелью нации;
- доля партий без единой войны (цель ворот 2: ≤ 5%);
- доля времени, когда у нации хотя бы одна война (среднее по нациям);
- закреплено земли миром (сумма по партии, пикселей), выплачено репараций (золота);
- первая война: медиана минуты объявления.

Остальные строки 01c остаются. Абляции `spread` и `no_armor` прогоняются как раньше. Дополнительная абляция `-profile all=no_claims` (`claimsChance_bp = 0`) нужна для одной строки: меняют ли претензии длину и исход партии по сравнению с одними репарациями.

`-analyze` для человека: моменты «мир с одним, в течение 60 с после него — война с другим» (мир как способ переброски), выбор цели (претензии / репарации), «давил дальше после выполнения цели» (цель выполнена ≥ 30 с, а мир не заключён).

**Карта.**
- `_PairStatus` (заготовка 02a) заполняется реальными статусами: мир — тонкая светлая линия, война — тёмная с каймой, перемирие — штрих. Войны между ИИ видны тем же стилем.

## 10. Edge cases

- Объявление на соседа, у которого ещё нет общей границы, — `NoContact`; граница появилась через расползание — можно.
- Две войны одной нации с разными соседями — разрешено игроку; ИИ `base` держит одну свою (но может быть атакован другими).
- Цель выполнена, но нападающий не мирится — война идёт, кнопка горит, пока условие держится; на 8-й минуте белый мир сам (то есть линия фронта, без остатка района и без дани).
- Защитник выполнил победу обороны, нападающий параллельно — свою цель: мир получает первая команда в очереди.
- Нация пала во время войны с третьей стороной — 4.5; `PendingPeace` по паре с ней снимается.
- Дань плательщику не по карману — платит, сколько есть, без дезертирства.
- Перемирие истекло, а дань ещё идёт — дань живёт своим сроком (при стартовых ручках они совпадают).
- Район частично в воде — `ClaimTotal` считает только сушу защитника; меньше `claimMinPixels` — `ClaimInvalid`.
- Карман из одного пикселя — тоже карман.
- Дивизии стоят у мирной границы, и сосед объявляет войну — работают сразу, без 30 с переброски. Это и есть смысл держать их там.
- Реплей формата 4 — код 2.

## 11. Acceptance criteria

1. Тесты Фундамента и 01c зелёные без смены ожиданий, кроме тех, что проверяли «контакт = война» (их переписать на объявленную войну; список в описании PR). `CoreHasNoForbiddenApis` проходит.
2. Валидация: на каждую причину `TargetInvalid`, `NoContact`, `AlreadyAtWar`, `TruceActive`, `ClaimInvalid` (все четыре условия), `NotAtWar`, `NoOffer`, `PeaceCooldown`, `OrderInvalid` — тест: команда отклонена, мир не изменился.
3. Без войны пиксели между нациями не переходят 3 000 тиков подряд (сиды 1–10, ИИ выключен); расползание по ничьей идёт как раньше.
4. `OccupiedLen`, `ClaimHeldLen`, `Pixels` после каждого тика совпадают с пересчётом с нуля (`DerivedStateMatches`, сиды 1–10, 6 000 тиков, с войнами).
5. Четыре вида мира на синтетической карте дают таблицу 4.3 пиксель в пиксель и числа раздела 5 (709, 600, 250, 640); сброс `HoldAtt` при потере района; белый мир по сроку на `maxWarTicks`.
6. Карман: синтетическая компонента `D` внутри `A` переходит `A` при мире; компонента, касающаяся третьей нации, не переходит; компонента со столицей не переходит.
7. Гибель нации на войне: занятое ею закрепляется за держателями, её земля ничья, войны с ней закрыты, дань снята.
8. Мир сбрасывает дивизии пары в тыл и приказы в оборону; перемирие запрещает объявление до `TruceUntil`, потом статус «мир».
9. `HashJob = HashManaged` на 10 мирах с войнами; `-determinism 42` проходит; реплей из игры (≥ 3 объявления, оба вида цели, белый мир, принятие и отказ предложения ИИ) проходит `-replay`; формат 4 — код 2.
10. `-seeds 1-100`: код 0, строки раздела 7. Ожидания для описания PR, не обязательства: партий без войны ≤ 5%, войн за партию ≥ 2, у ≥ 50% войн исход — цель или победа обороны, а не срок. Таймер не обязан уйти (раздел 1).
11. Средний тик ≤ 0,25 мс; максимум тика мира — отдельной строкой; p99 ≤ 2 мс.
12. В игре: объявить войну с обеими целями, выбрать район с отказом и с успехом, увидеть прогресс цели, забрать выполненное, предложить белый мир, получить и принять / отклонить предложение ИИ, увидеть перемирие с таймером и дань, штриховку занятой земли, круг района, три стиля границы. Клики проверяет Никта на плейтесте, агент — скриншотами бенча (`-bench` объявляет войну за человека).
13. 60 fps на ×4 в 1080p с 8 нациями.
